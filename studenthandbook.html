CS Department Code of Conduct

The Student Handbook serves as the official guide for academic integrity, behavior expectations, and the progressive discipline system. The following violations are categorized for the Violation Monitoring & Suspension Decision Support System.

Categories of Offenses

🔴 Class A – Minor Offenses

First warnings, corrective actions, community service.

  • Habitual tardiness (3+ times/month)
  • Improper uniform / ID violation
  • Littering inside campus
  • Use of gadgets during class (non-academic)

🟠 Class B – Serious Offenses

Probation, parental conference, suspension (1-5 days).

  • Cheating / plagiarism (first offense)
  • Unauthorized absence (cutting classes)
  • Verbal harassment or disrespect
  • Vandalism or minor property damage

🔴 Class C – Grave Offenses

Suspension (5-20 days), recommendation for expulsion.

  • Physical assault / bullying
  • Cheating (repeat offense)
  • Possession of prohibited substances
  • Cyber misconduct / hacking attempts

Sanction Matrix & Suspension Guidelines

Offense Category 1st Infraction 2nd Infraction 3rd Infraction
Class A Minor Verbal Warning + Reflection Essay Written Warning + 2 Days Community Service Parent Conference + 1-Day Suspension
Class B Serious Probation (1 month) + 3-Day Suspension Extended Probation + 5-Day Suspension 10-Day Suspension & Loss of Privileges
Class C Grave Immediate Suspension (10 Days) + Hearing Semester Suspension / Recommendation for Dismissal Expulsion (permanent record)

The Suspension Decision Support System automatically recommends sanctions based on violation history and category. All decisions are reviewed by the CS Department Discipline Committee.

CS Department Specific Policies

  • Laboratory Misconduct: Unauthorized software installation, food/drinks inside lab → Class B offense.
  • Network Abuse: Bypassing firewalls, accessing restricted content → Class B or C depending on severity.
  • Code Plagiarism: First offense: grade deduction + mandatory ethics seminar. Repeat: Class B suspension.
  • Attendance in Capstone/Internship: Unexcused absences beyond 20% leads to automatic probation.
  • Academic Dishonesty: Use of AI without disclosure → treated as plagiarism.

Student Rights & Disciplinary Process

Every student has the right to due process. The discipline flow: Incident Report → Evaluation by Adviser → Committee Review → Sanction Recommendation → Appeal Window (3 days). The Suspension Decision Support System ensures consistent and fair application of the handbook.
